# MZ 导航系统 v1.0.4

把原来的静态导航站（hao.mazzz.cc）改造成带后台管理的 PHP 程序。**前台视觉与原静态站完全一致**，后台可管理分类、站点、搜索引擎、壁纸、公告、友链，并支持数据备份导出。

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| PHP | 7.0 以上（推荐 7.4 / 8.0 / 8.1 / 8.2） |
| 扩展 | `pdo`、`pdo_mysql`（或 `pdo_sqlite`）、`mbstring`；建议开启 `gd`、`curl`、`fileinfo` |
| 数据库 | MySQL 5.6+ / MariaDB 10+（**推荐**）；也支持 SQLite（零配置） |
| Web 服务器 | Nginx / Apache / IIS 均可，**不需要伪静态规则** |

## 二、安装步骤

### 1. 上传程序
把整个目录上传到网站根目录，例如 `/www/wwwroot/hao.example.com/`。

> ⚠️ **隐藏文件别漏**：程序里有两个以点开头的保护文件 —— `data/.htaccess`、`uploads/.htaccess`。部分 FTP 客户端默认不显示、也不上传这类文件，请务必确认它们传上去了。若宝塔面板解压，注意选「覆盖」并显示隐藏文件。
>
> 这两个文件的作用：`data/` 里的 `config.php` 含数据库密码，`uploads/` 里禁止执行 PHP。**在上传前就已存在**，不需要安装向导生成。

### 2. 设置目录权限
确保 `data/` 与 `uploads/` 目录可写（宝塔面板：右键 → 权限 → 755，属主 www）：

```
data/            可写（存放配置文件与备份）
data/backup/     可写
uploads/         可写
uploads/icon/    可写
uploads/wallpaper/ 可写
```

### 3. 创建数据库（宝塔）
面板 → 数据库 → 添加数据库，记下 **库名 / 用户名 / 密码**。

> 如果数据库用户有建库权限，安装向导也会自动创建数据库。

### 4. 运行安装向导
浏览器打开 `http://你的域名/install/`，按三步走：

1. **环境检测** — 标红的项必须先解决
2. **数据库配置** — 填宝塔里创建的库信息；程序会自动写入 `data/config.php`
3. **管理员与站点信息** — 设置后台账号密码、站点名称

安装完成后会**自动导入原站的 9 个分类 / 79 个站点 / 15 个搜索引擎**，无需手工录入。

### 5. ⚠️ 立刻删除 install 目录
```
删除  install/  整个目录
```
不删的话别人可以重新安装并清空你的数据。

### 6. 部署自检
访问 `http://你的域名/check.php?key=XXXXXXXX`，其中 `key` 是 `data/config.php` 里 `authkey` 的**前 8 位**。检查完请删除 `check.php`。

### 7. 登录后台
`http://你的域名/admin/`

## 四、后台功能说明

### 站点基础信息
站点名称、浏览器标题、关键词、描述、站点地址、ICP、版权、Logo（可上传）、favicon、Logo 尺寸、背景模式（固定图 / 随机壁纸 / 随机图片接口 / 纯色）、背景遮罩、搜索框提示、默认搜索引擎、搜索联想开关、侧栏菜单默认展开、跳转开关与方式、点击统计、公告/友链开关、天气（和风天气 Key + 城市 ID）、页脚 HTML、统计代码。

### 分类管理
增删改查、排序值、启用停用、批量操作。删除分类会连带删除其下站点（有二次确认并提示数量）。

### 站点管理
- 按分类筛选、按名称/网址搜索、按状态筛选、分页
- 图标：**内置 103 个图标任意选**（点「从内置图标库选择」），也支持上传图片或填图片地址
- 每个站点可单独设置：跳转保护、新窗口打开、nofollow、描述、排序
- 批量：启用 / 停用 / 删除 / 移动分类 / 开关跳转保护 / 重置点击量
- 直接在列表里改排序值后点「保存排序」

### 搜索引擎
增删改查、批量操作、设为默认。搜索地址用 `{q}` 表示关键词位置，例如：

```
https://www.baidu.com/s?wd={q}
https://cn.bing.com/search?q={q}
https://search.bilibili.com/all?keyword={q}
```

前台的切换方式有三种：**点搜索框下方的引擎选择条**（推荐）、点搜索框左侧图标逐个轮换、用 `/?t=标识` 直接指定。有「测试」按钮可验证配置。

#### 引擎选择条（搜索框下方）

搜索框下面会渲染一排引擎按钮，点一下即切换，页面不刷新；地址栏的 `?t=` 会同步变化，刷新或分享链接后仍是同一个引擎。

- 显示与否：后台 **站点设置 → 搜索框 → 搜索框下方显示「搜索引擎选择条」**（默认开启）。只有一个可用引擎时自动隐藏。
- 显示哪些：只显示在「搜索引擎」里**启用**的引擎，顺序与列表排序一致。
- 关闭 JS 也能用：每个按钮本质是 `<a href="?t=标识">`，脚本失效时退化为一次页面跳转，功能不丢。
- 窄屏（< 640px）自动变成**横向滑动**的一行，不会把页面顶下去或撑出横向滚动条。
- 选中项用该引擎的 `color` 填充；没有配置 logo 的引擎显示首字彩色圆标。

### 壁纸管理
单张上传 / 批量上传 / 外链壁纸。选「随机壁纸」背景模式时每次刷新随机取一张。

### 随机图片接口（背景）
背景模式选「随机图片接口」时，前台每次刷新都会换一张图。接口地址支持**一行一个、填多条**（最多 20 条，`#` 开头的行当注释），前台每次随机挑一条调用；填返回「一张图片」的接口，**不要填返回 JSON 的接口**。

#### 不用手打地址：内置预设 + 一键测活
后台「站点设置 → 外观与背景 → 随机图片接口地址」上方有一块**常用随机图接口**：

- **点「+ 名称」即填入**地址框（已在框里的会变成「已添加」，不会重复）。预设都是 2026-10-02 逐条实测、连取 5 次都能拿到真图的接口：原站同款的 MaZzz 二次元、鹿图（动漫/风景/美女）、Alcy（电脑/手机壁纸）、LoliApi、dmoe、paulzzh 东方、Picsum 真实照片。
- 标签为**橙色**的预设是 `http://` 接口（原站同款、鹿图系列）。站点若是 https，必须打开下方「由服务器代理拉取图片」，否则浏览器按混合内容拦掉。
- 点「测」用**你当前浏览器直连**测一次，报告成功/失败、图片尺寸、耗时 —— 验的是「302 模式」那条路。
- **「从 api.example.com 拉取接口清单」**：服务端去接口站取它自己的接口列表，挑出「返回图片」的，返回后同样可点「填入 / 测」。
- **「测试接口」**：按**已保存**的设置逐个地址实测，报告 HTTP 码 / Content-Type / 字节 / 尺寸 / 耗时 /（失败时）原因，并显示接口全挂时会回退到哪。验的是「代理模式」那条路。

> 「测」和「测试接口」不是重复：前者是访客浏览器直连（302 模式），后者是服务器抓取（代理模式）。两者都可用才是真的稳。

> 诊断接口 `api/bg.php?m=api&diag=1` **仅后台登录后可用**，且只诊断后台自己保存的地址 —— 它不接受外部传入的任意 URL（否则公开入口就变成了任意地址抓取代理）。

#### 各开关含义
- **追加随机参数防止缓存**（默认开）：接口地址不带随机参数时，浏览器/CDN 会一直返回同一张图 —— 这是最容易踩的坑，建议保持开启。
- **由服务器代理拉取图片**（默认关）：接口有防盗链、或站点是 https 而图片是 http（浏览器会按混合内容拦截）时开启。服务器拉图后回传，超时按「代理超时」设置。
- **失败重试次数**（默认 3，1..5，仅代理模式）：这类随机图接口多是把请求 302 给第三方图床，而图床会**间歇性**返回错误页（实测约 1/3 概率）。若一次失败就回退，首页背景会三不五时变回固定图；换个地址重试能把失败率压到很低。
- **单张图最大 KB**（默认 3072，256..8192，仅代理模式）：随机图接口常给出好几 MB 的原图（实测遇到 7.6MB 的），超过上限就丢弃并换地址重试，能明显加快首屏。超限时不会把整张图拉完 —— 边下边判、一超限立刻断开。
- **自动换图间隔**：填 0 = 只在刷新页面时换；填 30 表示停留期间每 30 秒自动换一张（最小 5 秒，新图加载完成后才替换，不会闪白）。

接口挂掉/返回的不是图片时**不会白屏**，会依次回退：壁纸库随机 → 固定背景图 → 兜底背景色。

> 实现要点：前台背景地址指向 `api/bg.php?m=api` 而不是接口本身。因为把接口地址直接写进 CSS 的 `background-image` 时，同一个 URL 会被浏览器缓存，访客永远只看到同一张图；经过本文件中转后每次响应都是 `no-store`，且目标地址每次带新的随机参数，缓存必然击穿。

### 数据备份
导出 SQL（标准 MySQL 建表+插入语句，可直接导入 phpMyAdmin 恢复）或 JSON；也可清理过期点击明细、清空统计。

### 账号安全
修改密码、退出登录。页面只显示**当前账号**的登录次数与上次登录 IP 两个字段（不是完整的登录历史列表）。

## 六、从原静态站切换

原站 `index.html` 可以保留（不会冲突，但建议删除以避免入口混乱）。程序已把原站 79 个站点的**真实地址重新提取**（原来是被 `jump.php?url=` 包裹的），所以后台看到的都是真实 URL，方便你修改。原站两个站内链接（`/ip`、`/base64/`）保持原样指向站内路径，如有对应程序可直接用，没有的话在后台删掉或改掉即可。

原站的背景图用的是外部随机图接口 `api.example.com/API/img.php`，本程序默认改为**自带渐变背景图**。想恢复原效果：

```
后台 → 站点设置 → 背景模式 → 选「随机图片接口」
点预设里的「+ 示例 随机二次元」→ 保存
```

这个接口实测有两处脾气，所以**建议把「由服务器代理拉取图片」也打开**：① 它自己 302 到第三方图床（花瓣 / 米哈游 / 堆糖…），其中花瓣约 1/3 概率返回错误页；② 有时给出好几 MB 的原图。开了代理模式后，这两条都由服务器兜住（失败自动换地址重试、超大图丢弃），访客端只会看到本站 `api/bg.php` 一个地址，也不会遇到浏览器代理/混合内容的问题。

接口是 http 的（`https://` 版本 404），站点若已上 https 也必须开代理模式，否则浏览器会按混合内容拦掉。如果发现背景一直不变，先检查「追加随机参数防止缓存」有没有被关掉。

## 七、常见问题

**Q：安装时提示「数据库连接失败：could not find driver」？**

这是 PHP 没加载对应的 PDO 驱动，跟程序无关。第 2 步页面上不可用的那个数据库类型会直接置灰并标注原因。

- 选了 SQLite → 需要在 `php.ini` 里启用 `extension=pdo_sqlite`
- 选了 MySQL → 需要在 `php.ini` 里启用 `extension=pdo_mysql`

改完**重启 PHP**（宝塔：软件商店 → PHP → 设置 → 服务 → 重启）再试。也注意 `extension_dir` 必须指向 PHP 自带的 `ext` 目录（有的 Windows 包默认写成相对路径 `ext`，会加载不到）。

**Q：安装时提示 `SQLSTATE[23000] ... 1062 Duplicate entry '1' for key 'PRIMARY'`？**

这是**库里还留着上一次安装的数据**，而安装脚本给分类显式指定了 `id`（1、2、3…），再次插入时撞上主键。`CREATE TABLE IF NOT EXISTS` 不会清空已存在的表，所以「删了 `data/install.lock` 重装」必踩。

三种解法：

1. **清空旧表再装**（最干净，**会丢数据**）——先确认前缀，再执行：
   ```sql
   DROP TABLE IF EXISTS 前缀_category, 前缀_site, 前缀_search, 前缀_wallpaper,
     前缀_notice, 前缀_link, 前缀_admin, 前缀_hit, 前缀_setting;
   ```
2. **换一个空库名重装**（不动现有数据）——适合线上已有数据、想另起一套的情况。
3. **改代码让它幂等**——把 `install/index.php` 里的分类插入改成 `INSERT ... ON DUPLICATE KEY UPDATE`，或在导入前先 `TRUNCATE` 相关表。

> ⚠️ 如果这台机器上已经有真实数据，**不要执行方案 1 的 DROP**。先导出备份，或改用方案 2。

**Q：输入特别长的网址或名称，保存后会怎样？**

不会报错，会**按字段上限自动截断**并记进 `data/log/`。各字段上限（数据库列宽）：

```
分类名 50   站点名 80   站点地址 500   站点描述 255
引擎名 30   引擎标识 30  搜索地址 500
公告标题 80  友链名 50   壁纸地址 255
```

后台表单也已经加上 `maxlength`，正常输入不会撞到上限。之所以做自动截断而不是报错：MySQL 默认开启严格模式（`STRICT_TRANS_TABLES`），超长数据会直接抛 `Data too long` 异常；SQLite 则会静默截断。两种驱动表现不一致，统一按列宽截断最稳。

**Q：某个页面突然变成「服务器处理请求时出错」？**

这是程序的兜底错误页——说明有异常被捕获了，**详情写在 `data/log/年月.log` 里**。若 `data/config.php` 里加了 `'debug' => true`，页面上会直接显示异常内容。

**Q：上传大图片提示失败？**

改 `php.ini`：`upload_max_filesize = 10M`、`post_max_size = 12M`，重启 PHP。

**Q：后台进不去 / 一直跳登录页？**

1. 检查 `data/` 目录是否可写；
2. 检查浏览器是否禁用了 Cookie；
3. 删除 `data/login_fail.json` 解除登录锁定。

**Q：忘记后台密码？**

新建一个临时文件（例如 `genhash.php`），内容只有一行：
```php
<?php echo password_hash('你的新密码', PASSWORD_DEFAULT);
```
浏览器访问它，复制输出的哈希串，然后执行 SQL：
```sql
UPDATE 前缀_admin SET password='粘贴哈希' WHERE username='admin';
```
改完**立刻删掉** `genhash.php`。

> 也可以顺便清掉 `data/login_fail.json`，避免还被登录锁挡着。

**Q：能不能换后台目录名？**
可以，把 `admin` 目录改名即可（如 `mz-admin-3f7c`），程序内部用的是相对路径，无需改代码。

**Q：支持子目录安装吗？**
支持。站点地址留空时会自动识别当前域名与子目录。

## 八、安全建议（重要）

1. **装完立刻删除 `install/` 目录**（后台首页会一直提醒你）
2. **删除 `check.php`**
3. **把 `admin/` 目录改名**，可大幅降低被扫描爆破的概率
4. 使用 12 位以上强密码，别用 `admin/123456`
5. 为站点开启 HTTPS
6. 定期在「数据备份」导出数据

### ⚠️ 用 Nginx 的必看（.htaccess 对 Nginx 无效）

程序自带的 `data/.htaccess`、`uploads/.htaccess` **只在 Apache 下生效**。Nginx 用户请把下面这段加进站点的 `server { }` 里（宝塔：网站 → 设置 → 配置文件），否则别人可能直接下载到 `data/data.sqlite`：

```nginx
# 数据目录、安装向导、自检工具一律禁止外部访问
location ~ ^/(data|install|check\.php) {
    deny all;
    return 404;
}

# 上传目录只放行静态文件，禁止执行 PHP
location ^~ /uploads/ {
    location ~ \.php$ { deny all; }
}

# 上传目录里的 .htaccess 之类的点文件也别暴露
location ~ /\. {
    deny all;
    return 404;
}
```

改完 `nginx -t` 测试再重载。**这一条比删 install 目录更重要**，建议装完立刻加上。

## 九、技术说明

- 数据库表前缀默认 `mz_`，安装时可自定义
- 密码使用 `password_hash()`（bcrypt）存储，非明文
- 后台所有写操作都带 CSRF 校验，跳转接口有 URL 协议白名单（拒绝 `javascript:` 等）
- 上传目录禁止执行 PHP，`data/` 目录禁止外部访问
- **字符列上限自动从建表语句解析**（`MzDb::limits()`），写入前按列宽截断，避免 MySQL 严格模式抛异常、也避免两种数据库行为不一致
- **全局异常/致命错误兜底**：未捕获的错误会给出可读页面（API 路径返回 JSON），详情写入 `data/log/`，不会白屏
- 时间字段统一用 `int` 时间戳存储，不受 `MySQL NO_ZERO_DATE` 等模式影响；代码中无 `GROUP BY`，兼容 MySQL 8 的 `ONLY_FULL_GROUP_BY`
